# Capturas de tela do projeto

Esta pasta reúne a capa do README e as capturas de tela de apresentação da aplicação **A Arquitetura Invisível do Estudo**.

## Arquivos principais

- `capa-readme.svg` — capa vetorial horizontal utilizada no topo do README principal.

## Sugestão de organização

Use nomes simples e consistentes, por exemplo:

- `captura-01-abertura.png` — título, autoria e resumo do projeto.
- `captura-02-rotina-dores.png` — capítulo sobre rotina e desafios.
- `captura-03-matriz-afinidades.png` — matriz de afinidades.
- `captura-04-tear-rotina.png` — visualização de coocorrências.
- `captura-05-fichario-vivo.png` — explorador de evidências.
- `captura-06-metodologia-creditos.png` — notas metodológicas e autoria.

## Boas práticas

- Prefira PNG para capturas que contenham texto e interface.
- Verifique a legibilidade antes de publicar; evite imagens tão estreitas ou reduzidas que tornem o texto ilegível.
- Não inclua dados pessoais, informações privadas ou conteúdo que não esteja autorizado para divulgação.
- Use texto alternativo descritivo ao inserir as imagens no README ou em documentação.
- Mantenha apenas as capturas que ajudem a compreender o produto ou documentar sua evolução.
